            How to read this page

            Working files can be staged for a future commit. Commits are local history; an upstream shows the locally known relationship with a remote branch. Ahead/behind counts use existing local tracking data and may be stale until fetched elsewhere. This page only reads local Git status. It never stages, commits, fetches, pulls, pushes, switches branches, or changes files.
